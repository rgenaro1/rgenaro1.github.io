# Dantix Leather Vision

App de taller para medir mantas y digitalizar moldes. Corre 100% en el navegador: la foto no se sube.

**Abrir:** https://rgenaro1.github.io/dantix-vision/

## Instalar en el teléfono

- **Android (Chrome):** menú ⋮ → Instalar app, o el botón del home.
- **iPhone (Safari):** Compartir → Agregar a pantalla de inicio.
