# Dantix Leather Vision

App de taller para medir mantas y digitalizar moldes. 100% en el navegador.

**URL:** https://rgenaro1.github.io/dantix-vision/

Ya están en esta carpeta: `manifest.webmanifest`, `sw.js`, `icon.svg` y un `index.html` cargador.

## Un paso para dejarla completa

El HTML de la app (~1 MB) no entra por la API de GitHub de una sola vez.

1. Bajá el ZIP `dantix-vision-pages.zip` (te lo dejé en el chat).
2. En GitHub: [dantix-vision](https://github.com/rgenaro1/rgenaro1.github.io/tree/master/dantix-vision) → **Add file** → **Upload files**.
3. Subí el `index.html` del ZIP (reemplaza el cargador).
4. Esperá ~1 minuto y abrí https://rgenaro1.github.io/dantix-vision/

## Instalar en el teléfono

- Android / Chrome: menú ⋮ → Instalar app.
- iPhone: Safari → Compartir → Agregar a pantalla de inicio.
